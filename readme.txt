Comprehensive HPOS-compatible WooCommerce Product, Order and Customer reports with Jalali/Gregorian dates, CSV/XLSX, print, saved and scheduled reports.

== Description ==

WooCommerce Advanced Reports adds a complete Reports area to WordPress admin. It includes store KPIs, product and inventory analytics, order/financial reports, customer analytics, currency-aware calculations, Jalali/Gregorian date support, CSV/XLSX export, printing, saved reports, background exports and scheduled email reports.

See README.md inside the plugin for the full report catalog, metric definitions and architecture notes.

== Installation ==

1. Upload and activate the plugin.
2. Ensure WooCommerce is active.
3. Open Reports > Settings.
4. Choose Gregorian or Jalali calendar and configure permissions/performance.
5. Open Reports.
